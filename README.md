# Light Polarization

An interactive demo of how stacked linear polarizing filters transmit light, following Malus's law exactly — including the classic "three polarizers" paradox: two filters crossed at 90° block almost all light, but inserting a third filter at 45° between them lets a good chunk of it back through.

Choose how many filter layers to stack and the angle of each one; the effect is applied live to an image, and a stage-by-stage transmission ladder shows the intensity remaining after each layer.

Plain HTML/CSS/JS, no build step, in the style of [dirdam/math](https://github.com/dirdam/math)'s apps (phyllotaxis, double pendulum, etc). Open `index.html` directly or serve the folder.
